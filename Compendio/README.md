# Compendio de Estructura de Datos

Banco de ejercicios por tema para preparar PP1 y PP2.

El compendio funciona como material transversal del curso: no pertenece a una ayudantía específica, sino que reúne ejercicios de práctica, enunciados y soluciones organizados por contenido.

## PP1

| Material | Contenido |
| --- | --- |
| [01 - Ruteos de Punteros y Arreglos](<PP1/01 - Ruteos de Punteros y Arreglos/README.md>) | Trazado de memoria, punteros, arreglos y acceso a datos. |
| [02 - Ruteos de Herencia y Polimorfismo](<PP1/02 - Ruteos de Herencia y Polimorfismo/README.md>) | Ruteo de POO en C++, herencia, polimorfismo y despacho dinámico. |
| [03 - Detección y Corrección de Errores](<PP1/03 - Deteccion y Correccion de Errores/README.md>) | Identificación de errores frecuentes de implementación. |
| [04 - Complejidad Algorítmica](<PP1/04 - Complejidad Algoritmica/README.md>) | Análisis de costo temporal y espacial. |
| [05 - Algoritmos con Listas Enlazadas](<PP1/05 - Algoritmos con Listas Enlazadas/README.md>) | Inserción, eliminación, recorrido y manipulación de nodos. |
| [06 - Algoritmos con Pilas y Colas](<PP1/06 - Algoritmos con Pilas y Colas/README.md>) | Uso de estructuras LIFO y FIFO en problemas algorítmicos. |
| [07 - Verdadero o Falso](<PP1/07 - Verdadero o Falso/README.md>) | Preguntas conceptuales de repaso. |
| [08 - Selección Múltiple](<PP1/08 - Seleccion Multiple/README.md>) | Preguntas de alternativas sobre contenidos de PP1. |
| [09 - Completar Conceptos](<PP1/09 - Completar Conceptos/README.md>) | Definiciones y relaciones conceptuales. |
| [10 - Ejercicios Integradores Tipo Parcial Real](<PP1/10 - Ejercicios Integradores Tipo Parcial Real/README.md>) | Ejercicios integradores con formato de evaluación. |
