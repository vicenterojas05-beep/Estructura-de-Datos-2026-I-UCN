## Uso recomendado

1. Revisa primero el enunciado o guía de la ayudantía.
2. Intenta resolver los ejercicios sin mirar la solución.
3. Contrasta tu propuesta con `SOLUCION.md` cuando exista.
4. Vuelve al [Compendio](../../Compendio/README.md) para practicar el mismo contenido con más variaciones.
